Windows 25H2 x64 / RAM 16 GB 向けの架空データ検証ツール

ZIP を空のフォルダーに展開してください。.NET の追加インストールは不要です。
モデル推論には Microsoft Visual C++ x64 Redistributable が必要です。不足する場合、モデルをダウンロードする前にログに案内を記録して終了します。公式インストーラー: https://aka.ms/vs/17/release/vc_redist.x64.exe
1. RunPreflight.cmd: インターネット接続やモデル読込を行わず、通常・試験・返却の架空表を実際の Builder、Rules、Validator、正式形式への変換で検証します。
2. RunQwen25.cmd: Qwen2.5 1.5B CPU の固定版を約1.93 GBダウンロードし、6陽性・6陰性の架空セルで実推論します。
3. 必要に応じて RunQwen35.cmd: Qwen3.5 2B text CPU 固定版を約1.54 GBダウンロードし、同じ検証を行います。同時には起動しないでください。
4. 各実行後、同じフォルダーの preflight.log / benchmark-qwen25.log / benchmark-qwen35.log を共有してください。ログには架空入力の集計・研究用モデルの架空出力・公開モデルのSHA-256・性能値を記録します。

モデルは専用の一時キャッシュに保存され、通常終了時に削除されます。初回のダウンロードとCPU推論には時間がかかります。強制終了した場合、一時キャッシュが残ることがあります。

学校PDF、学校URL、既存のアプリ保存データ、認証情報は読みません。学校データを送る機能、クラウドLLM、Webサーバー、採用・保存処理はありません。公開モデルのダウンロード以外の学校ネットワークアクセスは行いません。

Rulesの検証とモデルの検証は別です。Rulesで解決する例をAIの実用効果として数えません。モデルの直接検証では、日本語をそのまま読めるJSONにした研究用Providerを使用します。元の指示・スキーマ・SDKの既定サンプリングは維持します。Markdownコード枠、不正ID、不正な役割証明は厳格に拒否します。

このツールは品質合格や配布モデルの有効化を意味しません。入力は既に検討した開発用例で、独立した最終評価ではありません。PDF Reader/OCR、実際の学校資料、NPU、最小対応機のメモリは未検証です。プロセスの最大ワーキングセットと最後のPrivateMemoryを記録しますが、子プロセスの総メモリは含めません。

実行対象: Windows 25H2 x64 / RAM 16 GB (申告された機器条件。ここで実機実行済みという意味ではありません)
バックエンド: CPU のみ
ランタイム: Foundry.Local.WinML 1.2.4 / .NET 10 self-contained / Release
