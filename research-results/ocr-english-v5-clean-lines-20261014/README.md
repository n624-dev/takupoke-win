# 英語PP-OCRv5：原行を切らずに比較

研究のみ。公式 `PaddlePaddle/en_PP-OCRv5_mobile_rec_onnx`、revision
`3fafbc3b5dcf93dd72add9f48368be8a3a2cd33b`、7,848,423 bytes、SHA256
`b5f833dfc5d0eb71da397b4efa06ebeee9b431b690a47d6af40d77d8eabc557f`。
元の全438クラス辞書と公式BGR48を使用し、アプリのFP32入力／CTCを変更しない。

既消費192原行のBGRと固定Grayの計384呼出しを完了した。
見出しはBGR40/42一致、うち1行は高スコア誤読。Gray41/42一致、40行は正解かつnative0.8以上、
高スコア誤読0だが、不一致・低スコアが残る。小標本を全文書成功に換算しない。

日本語を含む本文は両字体・両条件とも0/72一致。
元の日本語を削除したり英数字部分だけを正解に置き換えたりしない。
閉じた出力の英数字suffix診断でも各字体3/24のみ一致し、教室の混同は解消しなかった。
空白6画像は文字を出力し、原画幅を越えた区間は拒否判定として保存した。
出力を切り詰めたり日本語用モデルと原文依存で合成したりしない。

見出し用の将来の比較候補に留め、アプリに有効化しない。
原画像・モデルだけをworkerへ渡し、原文は終了後の採点に使用した。
freeze／原出力／ハッシュを保持する。最終字体、セル所属、PDF取得、実Windows合格の証拠ではない。
