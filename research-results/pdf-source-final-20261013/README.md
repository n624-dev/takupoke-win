missing-body refusals. Each positive contains five pages,680 slots,2040 literal

acceptances, execution errors, manual corrections, OCR calls or LLM calls.
The Windows source's full CI38351294158 passed all seven required jobs.

Local source-process peak working set was at most131,772,416 bytes, below the
fixed2GiB component envelope for CPU16GB. This does not measure an entire running
Windows desktop or installer. Durations include native parsing/validation and
formal serialization, and are not an isolated recognizer speed claim.

This final supports the bounded source-first route for complete visible text
PDFs with verified original roles/geometry. It does **not** qualify image-only
PDFs, arbitrary font/colour/paint formats, missing-ToUnicode semantics, the
synthetically trained recognizer, a VLM, iPhone runtime or a device deployment.
Prior good data and explicit preview/adoption requirements remain unchanged.

Sources were created independently; no school document/value, output-guided
candidate choice or metadata repair entered generation or the reader. New font
pins and Apache2/OFL provenance are retained in the source receipt; font/PDF
binaries stay outside Git. Original output, generated-source identities and
pre-generation freeze are retained without deleting refusals.
