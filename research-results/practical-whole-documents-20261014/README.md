# 帳票全体と英数字specialistの開発比較（2026-10-14）

新しい架空の3クラス×5日×8時限、5ページの画像PDFを2字体で作成した。
正例は各120枠・本文360項目。各字体に曜日見出しを1か所欠いた負例も用意した。
字体は既に研究で使用したShippori Mincho／M PLUS Rounded 1cであり、最終評価・実学校資料・利用者の成功率ではない。
PDFの原画像取得経路で得た画素は生成画像とSHAで一致した。Windows OSのPDF再描画とは別条件。

項目は科目・担当・教室の値。未取得の項目を文字誤り率の分母に入れないため、
80枠の結果には120項目の欠落が別にある。欠落なしの最終行でも30／41項目の誤読は残る。
旧来の3項目訂正上限には収まらず、この結果を本番精度の資格や自動採用と扱わない。
誤読0を目標にした判定ではなく、文字誤り率、構造の取得、確認・訂正負担を分けている。

追加学習モデルは公式Torch英語PP-OCRv5を基盤にしたepoch4の独立モデル。
[学習データと比較・制限](../ocr-synthetic-training-20261013/ascii-english-v5-font-balanced-v1/README.md)。
英語辞書438字では日本語の本文を表現できない。日本語prefixはV6の原出力を保持した。
クラス見出しは物理的な左列と原出力のASCII条件で選び、モデル自身が出したクラス名を使う。
正解表からAl_1をAI_1へ置換していない。公式英語モデルのAI_1はIのnative scoreが約.751で保留、
追加学習モデルでは5ページとも自身の出力でAI_1となり、欠けていた40枠を取得できた。
不正クラスの負例を検証したという主張はしない。

英数字末尾は、CTCのprefix／tail位置の間にある、元画像の高さ全体で完全に白い縦帯で分ける。
行の右端まで全画素を保持し、非白画素を削除・塗りつぶししない。CTC位置は推定であり、
字形の輪郭や文字種の証明ではない。出力はprintable ASCII、元末尾と同じ文字数、
native CTC最低.8、reject確率最大.05、余白に重ならない位置という登録済み条件で選んだ。
confidenceや空白・大小文字を修正しない。
M PLUSの35項目が変化し、16項目改善・1項目悪化・18項目は誤読のまま。
正しかったB10がB1Oになる退行も残している。

末尾条件は追加英語推論1,290回（見出し60・末尾1,230）。原日本語推論は再実行していない。
各文書の追加処理は約15–18秒、同じプロセスの最大RSS約442 MB。
元日本語モデルの処理時間は別記録にあり、この数字だけを全文書時間としない。
確認候補は正例で8／16項目、原本crop付きのPrepare適格性を確認しただけで、
利用者が照合済み・文字訂正済みとはしていない。負例はいずれも拒否されたが、
無関係なOCR不確実性もあるので曜日欠落だけによる拒否資格とは扱わない。

記録は閉じたworker出力をbyte単位で複製した。curation-manifest.jsonのSHAと元のfreeze／receiptを保持する。
モデル・画素・PDF・ネイティブバイナリは含まない。重複するcached primaryは独立サンプルとして数えない。
Microsoft.ML.OnnxRuntimeの同梱パッケージは1.23.2。iOSは編集していない。

- preparation-failed-v1：絶対パスのasset guardで推論前に失敗。精度加点なし。
- whole-pages-v2：V5/V6の実行と原画像取得、原版とInlineLabel対応後の読み取り検査を別保存。
  worker終了後にscoreを準備した経緯もas-runのrunner／score版で保持。
- official-english-headers-v1：60回の公式英語モデル見出し比較。
- trained-english-headers-v1：60回の学習済み英語モデル見出し比較。
- tail-ownership-failed-v1：全ページの印字所有を検証する処理に単一末尾を渡したため、末尾候補0。
  60見出し推論のみ。製品の所有検証は弱めていない。
- white-gap-build-failed-v1：ローカル変数名衝突でビルド失敗。その後起動も失敗、推論0。
- white-gap-tails-v2：白帯条件の閉じた結果。原版reportのadditionalHeaderCallsとscope文言は
  見出しのみと誤記しているが、rawのrecognizerCallsとdecisionsは見出し＋末尾を数えている。
  本READMEが種別内訳の補足であり、凍結済みraw／reportは書き換えない。

shared-runtime-regression-v1は同じ条件をInfrastructureの共通実装へ移した再現検証。
追加1,290英語推論を実行し、4文書とも全文字・score・CTC区間・crop・reject確率・選択・出典・取得文書が一致した。
時間とRSSは一致比較から除外した。独立した精度評価の加点は0。定数ONNXと原画素分割の契約テスト13件も通過。
