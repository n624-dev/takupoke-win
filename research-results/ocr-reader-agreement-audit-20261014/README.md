# 異なる認識器が一致しても共通誤読が残る

追加推論0。既消費の同じ192原画像で、閉じた8種類のCTC読取結果の全28組を調べた。
Paddleは固定BGR、EasyOCRはその公式Gray64初回入力。
空でない原文字列の完全一致と、両者自身のminCTC0.8以上・padding支持を診断条件にした。
原文によるpair選択・文字補正・score転用は行わない。最終評価／モデル選定／採用ではない。

V5 mobile＋V6 mediumは正しい一致107行に対し、高スコアの同じ誤読が13行残った。
V6 medium＋smallも正しい一致114・同じ誤読9。V5 mobile＋serverは正87・誤25。
原文の空白を両方が落とす例や、教室の文字の取り違えがある。
相関する認識器の一致だけでは、元の文字列や原インクの取得を証明できない。

英語V5とのpairで誤り0の組があるが、主に見出ししか一致せず、日本語本文は一致しない。
正しい本文の取得不足を、誤り0の成功へ換算しない。
全組・各字体・項目別の一致と共通誤読をreportへ保存し、未使用最終字体は温存した。
