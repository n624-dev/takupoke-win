Research only; no model is qualified or active. The original PP-OCRv6 medium remains the fallback. Reserved Sawarabi Gothic/Mincho final fonts are unopened. iOS files are untouched. The closed adaptation subexperiment must not be conflated with the closed frozen-feature classifier experiment or the parent's separate minimum-width160 padding comparison.

## Reconstruction before learning

The official pinned medium standard ONNX keeps its CNN and local convolutional neck unchanged. Two original tensors are exposed: `p2o.pd_op.add.70.0` (local context) and `p2o.pd_op.swish.0.0` (shortcut), each FP32 `[batch,192,1,time]`. Torch reconstructs only the terminal global two-block SVTR: hidden192,8heads of24, SiLU FFN768, five copied LayerNorms, final residual shortcut. It has 890,112 parameters. The original complete18710 CTC classifier/dictionary is retained, blank0; no reduced dictionary or probability renormalization.

The first implementation incorrectly assigned final LayerNorm epsilon1e-5, while the original final initializer is1e-6 (earlier four1e-5). Its source/freeze/raw/failure remain immutable at the namespace root: text/CTC/decisions48/48 but feature/logit differences exceeded the prospective strict numeric gate. Read-only numeric tracing isolated the final norm; `epsilon-correction-audit.json` records the mistake. No gate was loosened.

`corrected-epsilon-v2` copies every original epsilon as an FP32 buffer. Same fixed consumed48 headers/blanks, original ink-bbox+2px/BGR48/native width320..960, and eight numeric batch1/2×width320/481/640/960 shapes. Text/CTC intervals and minimumconfidence.8+validWidth decisions all agree. Original observer probabilities/context/shortcut have maximum difference0. Natural input Torch feature maximum2.6703e-5, logit4.5776e-5, probability/emittedconfidence1.7882e-6. Registered thresholds feature1e-4/logit1e-3/probability1e-4 pass; floating byte equality is not claimed. Final logits are original full18710 values, without output repair. Initialization fidelity is not recognition quality, final evaluation or Windows/iPhone eligibility.

The corrected comparison took17.10s, peak1094.53MiB, concurrent Linux CPU2. A separate numeric-only backward dry run performs full18710 CTC and full18710 teacherKL, no optimizer step and no rendered/gold data. B16/T40 averaged.301s, B16/T120 .858s, peak1167.11MiB and finite gradients. State equality was checked. Three repeats per shape are a budget estimate, not isolated speed or native-platform measurement.

## Adaptation v1 — closed, original fallback

See `adaptation-v1/freeze.json` for the immutable protocol and source hashes. It uses fresh independent nature-phrase/code/case/confusable text, train4096positive+1024negative, dev768positive+128Japanese-retention+192negative. BIZUDGothic/KaiseiTokumin font families were consumed by the earlier closed head experiment; these are new literals/render seeds, not unused-font final claims. Prior literal manifests and parent oracle values are exclusion-only and never examples. Reserved final fonts remain unopened.

Whole-line original ink and Japanese prefix, baseline, relative height, spaces and internal gaps are retained. BGR48 and normalized-zero padding width320..960 stay fixed. Three per-row native map caches are FP32: context/shortcut/original final teacherfeatures. Training batches have exactly equal original time dimension, so global attention sees no added batch padding or artificial attention mask. Temporal center masking within validWidth applies only to the reject pool; recognition keeps all original native positions.

The CNN/local neck and original18710 matrix/bias remain frozen. SVTR lowLR adaptation, zero-initialized95ASCII classifier deltas, and independent rejecthead are trained. Because adapting features changes omitted-class logits, the old fixed-OTHER compressed teacher objective is not reused: this stage computes complete full18710 CTC and complete teacherKL, plus original-feature MSE. CJK retention, negative controls and source contradictions remain explicit checks, not guarantees. Identical provided/native-input tensors with different training literal labels are audited and excluded from optimization without guessed targets or false damage labels.

Eight epochs, fixeddev2/4/8 only, CPU2/B16,30min optimizer+evaluation budget, each cache split30min, ownRSS4GiB/minfree2GiB/diskaddition1.25GiB. Only completed registered epochs can be candidates; originalfallback selection and strict prospective final-opening gate remain. Wrong/damaged accepts, Japanese regressions and whole missing-prefix/script provenance are reported separately. A gate pass would only justify a separately frozen final/portable stage, not activate a recognizer or qualify a whole document.

Sources use explicit UTF-8/LF I/O and safe copied ONNX tensor/safetensors state; checkpoints, pixels and feature maps live outside Git. Standard ONNX is feasible in principle because the reconstructed operations are standard; trained graph merging/export fidelity/CoreML/native Windows/iPhone inference have not been validated. No custom Windows op or iOS edit is introduced.

The fixed8epoch experiment completed with original fallback: raw418/768→480, correctaccept369→327, wrong152→103, negative37→8, Japanese254/256→255 without regressions,40emptyblanks preserved.
