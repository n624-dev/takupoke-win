# 日本語を保持した英数字末尾の復旧と、帳票全体の回帰検証

復旧用経路で、既存の原画像の白い縦帯から分離できた英数字末尾にも、低confidenceの元観測を保持する。
日本語部分は元の日本語OCRから変更しない。数字を含むコード、元の文字数、reject 0.05、padding、
原画像範囲の条件を保ち、confidenceの昇格や自動採用をしない。
通常Readの0.8条件、既知のクラス名・表より上の見出しの保護も維持する。
低スコアの欄は原画像での個別確認が必要で、全体プレビュー・128項目上限・明示採用へつなぐ。

ここで使ったOCR・モデル・解析のsourceは変更していない。

| 各5ページ・120枠・360本文項目 | 字体0 | 字体1 |
|---|---:|---:|

| 高スコアの誤読（以前→今回） | 27→24 | 23→23 |

| OCR・解析時間 | 36.705秒 | 30.372秒 |

一致数は増えていない。字体0で3件多くの誤読を必須確認へ回し、正しい欄の確認も増えた。
unionは128項目以内だが、参照正解による事後集計であり、人の発見率・訂正時間ではない。
曜日・クラスを欠く4つの負例は拒否した。負例は完全取得の成功数へ加えない。
歴史的な3% CER条件の通過を、一般の本番資格や全資料の正解率としない。

Windows runnerはXeon Platinum8573C・物理2/論理4CPU・約16GiB RAM。
hybrid reader全6文書の最大working set584,744,960 bytes（約558MiB）。
モデル取得・初回smoke・人の照合時間を上記時間へ含めない。他のrunnerの過去時間との差を処理高速化としない。
一般の16GB PCでの目安は実機次第。原画像確認が必要な高スコア誤読は残る。
