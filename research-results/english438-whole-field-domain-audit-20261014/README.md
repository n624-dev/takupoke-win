# 英語specialistと日本語を含むfield全体の範囲

追加推論0、既消費原行の期待文字と公式English438全辞書の包含だけを事後監査した。
科目48・担当48・教室48は全て辞書外文字を含み、理想的な英語専用モデルでもfield全体を表現できない。
見出し42は全て表現可能。これは認識精度を測った結果でも、自動routingの判定器でもない。

英数字だけの別行を追加学習する場合も、日本語primaryを保持し、原文でJapanese prefixを切る処理や
suffixの正解をwhole-fieldへ合算する処理は導入しない。独立したfield領域・原位置・文字領域の
根拠と本文全体の検証が必要。辞書外文字の有無に期待文字を使って推論を分岐しない。

元192原行・公式辞書・閉じた英語reader rawのSHAをfreezeへ保持した。
source snapshotは終了後に保存し、登録freezeとbyte一致を監査した。モデル・画像・学校資料は公開しない。
