# 完全な白い列による分割案は文字境界を証明しない

追加認識0。英語V5比較へ渡した既消費512原行で、RGB成分が255と異なる全画素をインクとした。
完全な白列で分ける全高領域を先に原文なしで保存し、原出力を閉じてから数だけ採点した。
全512画像のインクを保持したが、正例384行中99行は領域数と印字文字数が一致しない。
一致285行も正しい字形の境界を示すものではない。白い間隔はUnicode空白の証明ではない。

文字の一部が分離した領域や複数字を含む領域が残るため、この方法を文字単位OCRへ接続しない。
原画像を削る閾値調整や文字別の正規化も行わない。blur/JPEG/未知字体への資格はない。
source snapshotは実行後に保存し、実行前freezeのSHAに一致することを別auditで記録した。
未使用最終字体は利用していない。
