# Physical raster region comparison (development)

One already-consumed independently invented unlabeled 40-slot RGB image, 3740×800. No original school PDF, text, image, PDF reader or cloud OCR is used. The previous two full-frame native arms remain immutable. This candidate is one finite comparison, not a model qualification or an unused holdout.

The original actual RasterRules/PdfGrid measured 89 closed rectangles. The original RuleMask endpoint defect left 3772 printed border pixels unmasked; the separately reviewed production fix changes only proved white endpoint handling. The fixed mask adds exactly those original black pixels and erases no white/character pixels. The candidate uses this pinned corrected mask, preserves the old one, removes only proved all-mask outer row/column strips, and rejects internal rules or non-rule loss. It produces 87 nonempty physical-cell crops and 3 outside metadata crops. Every original non-rule pixel (81,752) has exactly one planning owner. Outside crops use occupied pixel rows and white column gaps, with one observed row-height context; no text, role, gold coordinates or labels enter planning or inference.

Each of the 90 crops calls the same default NDL detector and cascade, sharing loaded models. Before unchanged PARSeq preprocessing, only completely RGB255 outer rows/columns inside each native prediction crop are trimmed. The original detector boxes, local recognition ROI, crop proof, raw text, actual token logits/uncalibrated softmax and exact integer global translation are retained. No box clipping, character subdivision, NMS, mask-alignment correction, text selection, deduplication, confidence threshold change or alternative adoption occurs. The original PARSeq rule `height > width * .8` still triggers CCW90 rotation; each actual call logs this predicate and original dimensions. Actual per-model inference counts are reported separately from the 90 planned region requests.

The complete pixel planning ledger proves only source region ownership. Returned OCR boxes may still overlap, omit original ink, cross their region, or contain wrong text. `sourceAdoptionEligible` is solely the observed geometry/ownership guard; it is not a safety or qualification claim. The host subsequently checks original ink coverage, actual Strict/Builder/Rules/Validator and the independent complete literal formal oracle. Text and tuple diagnostics are scored offline only. Detector confidence is not transcription confidence; token softmax is uncalibrated and has no adoption threshold.

The collector pins all runtime/source/model/input/plan bytes before inference, preserves partial raw bytes, and bounds one owned process group at 420 seconds / sampled 3 GiB RSS / polling 32 MiB output. Shared pages can be counted twice; these measurements are not a Windows physical-device requirement or an allocation hard cap. Runtime/serialization failures stay unassessed rather than counting as wrong text or correct negative rejection. No native calls were made during the 13 host counterexample tests.
