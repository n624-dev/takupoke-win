# 時間割変更XLSXの行除外

2026-10-09。配布済みWindows版のmain（5733869）から実装した。
PDF復旧研究ブランチの実験コードは取り込んでいない。

## 動作

- 日付と曜日の不一致・未知の曜日、曜日だけの行を通常解析で拒否する。
- 元の物理行番号・見出し・保存値を確認画面に保持し、利用者が選んだ行だけを除外する。
- 選択後にも確認が必要。キャンセルは許可や正常結果を書き換えない。
- 許可は原本ID・SHA・補完年度・解析版・物理行番号に限定する。
- 再選択・内容更新・年度や解析版の変更で無効にする。元の内容へ戻しても復活させない。
- 確定直前に実ファイルの識別情報とSHAを再確認する。
- 許可・正常結果・成功履歴を同じSQLiteトランザクションで保存する。
- 日付・学年・クラス・数式位置・結合セルなどの問題は、行除外で隠さない。
- 除外はクラス展開と「全」の候補収集より前に行う。空の正式結果は拒否する。
- 未確定・失敗時は前回正常結果を保持する。詳細画面は適用中の行数と番号を表示する。

## 検証

資料は独立して作成した完全架空のOOXML ZIPを使用する。
元資料・名前の置換資料・原文から生成した期待値は使用しない。

LinuxでCore 183件・Integration 139件が成功した（失敗・skipともに0）。
追加の読み取りテストと保存テストでは、上記の拒否・無効化・再起動・保存失敗時のロールバックを検証する。
最初の全除外テストは、プレビューに残る不一致行を誤って空と期待して失敗した。
プレビューは元の授業を保持する仕様に合わせて一件の存在を検証し、
正式保存時に全行を除外するとEmptyで拒否する条件は維持した。

Windows UIテストは実ファイル取得・実解析から前回正常結果と今回の失敗を準備する。
実CheckBoxとDialogを操作し、キャンセル・二段階確認・保存結果・再起動後の保持を検証する。
操作はAutomationId・実際のコントロール状態・観測した表示領域に基づく。
固定した画面座標や許可・解析結果の注入は使用しない。

Windowsでのビルド・画面操作と、同じソースのActionsは確認中。
Windows実機の導入・学校ファイルとの照合は未確認。
