# XLSX曜日の明示補正

曜日と日付の不一致で解析が失敗した場合、日付から正しい曜日を計算する操作を提示します。印字された曜日と計算結果を確認し、利用者が承認した場合に限り解析します。元のXLSXは変更しません。未知の曜日、日付の不備、数式キャッシュの欠落、その他の解析エラーはこの操作で無視できません。

承認は選択した原本の識別情報・内容SHA-256・年度・Parserバージョンに限定し、解析結果と同時に保存します。同じ内容の更新確認では再利用します。原本内容の変更、選択し直し、年度やParserの変更で無効になります。変更後に以前の内容へ戻っても承認は復活しません。承認待ちの間に資料が更新された場合は中止し、前回正常結果を維持します。
