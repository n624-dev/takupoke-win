# ローカルAIの現在地（2026-10-15更新）

**モデル接続・配布に加え、提供された3種類のPDFで、文字情報を優先した取り込みまたは原画像確認への経路を検証した。画像OCRの一般的な正解率と、人による確認・訂正時間は別に評価する必要がある。**
OCRの誤読0を導入条件にせず、文字誤り率、枠の取得、原画像による確認・訂正負担を分けて評価する。
画像OCRの以下の数値は架空資料の比較・修正後の回帰検証であり、利用者の実資料での成功率ではない。

文字情報のあるPDFでは、描画互換性・学年の所属・分割欄・全角時刻を改善した。提供された時間割は680枠で3項目、試験表は510枠で注記見出し1項目の原画像確認へ進み、返却表は通常のnative取り込みを通った。追加学習やモデル変更による精度向上として数えない。[native PDFの条件・検証範囲](native-pdf-compatibility-20261015.md)。

今回の実装は[CI全7ジョブ](https://github.com/n624-dev/takupoke-win/actions/runs/38711108154)とWindowsの829 UI項目を通過し、原画像確認・訂正・注記・採用・保存後の再起動を検証済み。Integration 1071件／Core 288件、Node.js 20警告0件。[配布版0.1.0-dev.10440](https://github.com/n624-dev/takupoke-win/releases/tag/v0.1.0-dev.10440)に今回の変更を含めた。配布全8ジョブ、x64の6導入状態で各829～830 UI項目を確認し、公開6ファイルとZIP内の全同梱ファイルのSHA・ビルド元を照合済み。[配布記録](../research-results/native-pdf-integration-20261015/installer-release-receipt.json)。
